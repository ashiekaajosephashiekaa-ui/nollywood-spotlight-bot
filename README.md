# Nollywood Spotlight Telegram Bot

Telegram bot for Nollywood Spotlight — movies, trivia, stats, and referrals.

- Bot: https://t.me/Nollywoodsspotlightbot
- Website: http://www.nollywoodspotlight.org

## Commands
- /start — Main menu
- /help — Show all commands
- /trivia — Play Nollywood trivia
- /movie — Random movie suggestion
- /stats — Bot statistics
- /about — About this bot

## Admin
- /adminstats — View user count
- /broadcast <message> — Send message to all users
